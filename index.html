FAQ

Pertanyaan yang paling sering ditanya. Kalau masih bingung, chat langsung ke bot.

Beneran bisa upload file 2GB?
Iya! Bot ini pakai MTProto hybrid (bukan Bot API biasa yang cuma 50MB). Jadi file besar tetep bisa masuk. Cocok buat project Flutter dengan asset gede.
Format project yang di-support apa aja?
Untuk Build APK: ZIP project Flutter (wajib ada pubspec.yaml). Untuk Deploy Web: file .html tunggal atau ZIP project web (wajib ada index.html). Untuk tools mod: ZIP project Flutter juga.
Berapa lama proses build?
Tergantung ukuran project. Rata-rata 3-7 menit untuk project standar. Build di mode Debug lebih cepat, mode Release lebih lama karena optimasi. Karena sistem kami tanpa antrean, file lu langsung diproses begitu masuk.
Premium harian Rp 1.000 itu maksudnya gimana?
Bayar Rp 1.000, akun lu jadi premium selama 24 jam penuh. Selama itu, lu bisa pakai semua fitur build dan tools tanpa batas. Gak ada sistem credit, gak ada potong-potongan. Habis 24 jam, tinggal perpanjang lagi lewat bot.
Ada paket lebih hemat gak?
Ada! Premium 7 hari Rp 6.000 (hemat Rp 1.000) dan Akses Permanen Rp 20.000 (bayar sekali, akses selamanya). Semua paket akses fitur yang sama, cuma beda durasi.
Pembayaran lewat apa?
Bisa QRIS (scan langsung di bot) atau DANA (transfer ke nomor yang dikasih bot). Status premium otomatis aktif setelah pembayaran dikonfirmasi.
Ada garansi kalau build gagal?
Kalau gagal karena error di sisi server bot, premium lu gak berkurang dan bisa langsung coba lagi. Kalau gagal karena kode project lu sendiri, bot kasih log error lengkap + analisa penyebab biar lu bisa perbaiki.
APK-nya bisa langsung diinstall?
Bisa! APK hasil build udah signed dan siap diinstall di device Android lu. Kalau mau publish ke Play Store, perlu signing key sendiri (bisa di-setup di project lu sebelum build).
